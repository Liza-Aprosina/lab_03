# ЛР 3. Каталог книг

Вариант 1 — библиотечные книги. Апросина Елизавета Денисовна

## Запуск

Открыть терминал в папке `lab_3`:

```bash
python3 -m catalog
```

Пример добавляет три книги, показывает поиск, сохраняет их в `out.json`,
загружает в другой каталог и удаляет одну книгу.
При повторном запуске `out.json` перезаписывается.

Тесты:

```bash
python3 -m unittest discover -s tests -v
```
